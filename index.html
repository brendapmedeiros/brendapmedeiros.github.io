Sobre

Atuo na interseção entre dados, operação e automação. Tenho base prática em suporte fiscal, atendimento, manutenção de carteira de clientes, CRM e relatórios de gestão — repertório que uso para entender processos reais antes de propor uma solução técnica.

Menos dado solto. Mais dado confiável.

Meu foco é construir soluções que deixam claro de onde o dado veio, como foi tratado, quais regras foram aplicadas e como o próximo profissional consegue manter a entrega.

  • Engenharia de dados: pipelines em Python, SQL, APIs, modelagem relacional e organização de camadas para consumo analítico.
  • Qualidade & governança prática: validações, data profiling, critérios de consistência e documentação para reduzir erro silencioso.
  • BI com base técnica: Power BI, DAX, Power Query e Microsoft Fabric conectados a modelos mais limpos e rastreáveis.

Como trabalho

Um projeto de dados não começa no gráfico. Começa na pergunta, na fonte e na regra de negócio. Minha abordagem prioriza clareza, rastreabilidade e manutenção.

Entendo o problema

Mapeio a pergunta de negócio, quem usa a informação e qual decisão depende dela.

Organizo fontes e regras

Identifico origem dos dados, campos críticos, inconsistências e regras de transformação.

Modelo para consumo

Crio tabelas, dimensões, fatos ou estruturas relacionais pensadas para consulta e análise.

Automatizo o fluxo

Reduzo tarefas manuais com scripts, APIs, orquestração e processos repetíveis.

Valido qualidade

Aplico checagens, testes, logs e critérios claros para evitar erro chegando no relatório.

Documento a entrega

Registro decisões técnicas, instruções de uso e próximos passos para evolução do projeto.

Projetos

Data Quality Pipeline

Monitoramento de qualidade de dados

Pipeline modular para acompanhar a saúde de bases de dados com validações, métricas de qualidade, detecção de anomalias e visualização do histórico de falhas.

Fonte de dados → Airflow DAG → Great Expectations → Persistência de resultados → Dashboard Streamlit → Alertas de falha
ProblemaBases inconsistentes chegavam silenciosamente até dashboards e relatórios, sem alerta ou rastreio de erro.
SoluçãoRegras de qualidade com Great Expectations, execução orquestrada e resultados persistidos para acompanhamento.
ResultadoHistórico de ocorrências, visão de falhas críticas e estrutura pronta para evoluir com novos checks.
Python Great Expectations Airflow Streamlit Data Quality

Fabric & Analytics Engineering

Pipeline comercial com modelagem dimensional

Modelo analítico em Microsoft Fabric com camada dimensional, medidas DAX e relatório em Power BI para acompanhamento de vendas, mix de produtos e perfil de clientes.

Dados comerciais → Lakehouse Fabric → fato_vendas + dimensões → Semantic Model → Power BI
ProblemaMétricas comerciais dispersas, sem modelo centralizado, histórico claro ou camada confiável para análise.
SoluçãoModelagem com fato_vendas, dim_produto, dim_cliente e dim_data; medidas DAX organizadas por contexto de negócio.
ResultadoCamada analítica reutilizável, relatório interativo e estrutura mais fácil de auditar e evoluir.
Microsoft Fabric Power BI DAX SQL Modelagem Dimensional

API & Banco de Dados

Circuito TVO

MVP para centralizar informações sobre trilhas, eventos ambientais, biodiversidade e métricas de uso em Teresópolis, com dados reais do PARNASO e estrutura pronta para consulta via API.

Frontend → API Express → Prisma ORM → PostgreSQL/Supabase → Deploy Railway → Métricas de acesso
ProblemaDados de ecoturismo dispersos, sem uma fonte centralizada para consulta, análise ou evolução do produto.
SoluçãoAPI REST com modelagem relacional, Prisma, seed com dados reais e rastreamento de acesso via Intersection Observer.
ResultadoRotas documentadas, deploy funcional e base estruturada para novas análises sobre uso e interesse dos visitantes.
Node.js Express PostgreSQL Prisma Railway
